# Fari App — Mobile Prototype

Static HTML prototype of the Fari video app experience.

## Run locally

```bash
node server.js
```

Open http://127.0.0.1:4175/app.html

## Contents

- `app.html` — phone-frame prototype with 5 screens: Templates, Me, Create, Paywall, Result
- `company.html` / `contact.html` / `privacy.html` / `refund.html` / `terms.html` — legal pages
- `assets/` — template thumbnails, videos, logo
